# koi-ascii

Lagoa de carpas em ASCII, num único `index.html` (sem dependências). Abra o arquivo no navegador.

- Cardumes, correnteza, ondas na água, vitórias-régias e pétalas
- Chuva, sapo/libélula, ciclo de dia e noite com vagalumes
- Som sintetizado (WebAudio), salvar imagem e link com as configurações
